# Alert coverage and investigation guide

Every metric panel has guidance in its question-mark tooltip. These are initial operational thresholds, not universal service guarantees. Review them with the application owner and storage team. A chart does not send notifications by itself: SUSE monitors evaluate health, and a notification channel/routing rule delivers messages.

## Tags for manual notification rules

All 33 custom monitors keep `sre-dashboards`. A shared monitor can have more than one dashboard tag. SMTP and notification routing are configured manually.

| Tag | Dashboard | Custom monitors |
|---|---|---:|
| `dashboard-applications` | Instrumented apps | 2 |
| `dashboard-platform` | Kubernetes Platform Health | 20 |
| `dashboard-traefik` | Traefik Ingress Health | 6 |
| `dashboard-resources` | Workload Resource Efficiency | 1 |
| `dashboard-harvester` | Harvester VM & Host Health | 5 |
| `sre-dashboards` | All project dashboards | 33 |
