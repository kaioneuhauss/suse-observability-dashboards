# Optional configuration fragments

Start with [Prepare your environment](../docs/prerequisites.md), then follow your module guide. These YAML fragments are for existing server or Traefik configurations. Merge them with the settings owned by your Helm/Rancher/Fleet installation; do not replace complete values with a fragment.

The [OTLP guide](../docs/otlp.md) shows how to apply the server ingress settings with Helm. The [Traefik guide](../docs/traefik.md) covers metrics configuration.
